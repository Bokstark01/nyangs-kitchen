탐정모드

잃어버린 고양이,
동네 급식소가 함께 찾아요

길고양이 급식소에는 동네 고양이들이 모여요. 집을 나간 고양이도 배가 고프면 급식소를 찾아올 수 있어요. 탐정모드는 잃어버린 곳 가까운 급식소 주인들에게 차례로 도움을 청해요.

  1. 유실 신고앱의 탐정모드에서 사진, 특징, 잃어버린 날과 장소를 알려주세요.
  2. 운영자 확인장난이나 악용을 막기 위해 운영자가 신고 내용을 확인해요.
  3. 50m → 100m 알림잃어버린 곳에서 50m 안 급식소 주인부터, 필요하면 100m까지 넓혀 알려요.
  4. ‘봤어요’ 답장급식소 주인이 본 시간과 장소를 답장하면 보호자에게 바로 보여요.

🐾 고양이 안전을 위해 급식소의 정확한 위치는 신고한 분께도 공개하지 않아요. 알림은 급식소 서버 백업에 동의한 급식소 주인에게만 가요.
