냥's 키친 개인정보처리방침

시행일: 2026년 10월 8일 · 버전 1.0

[상호명](이하 "운영자")은 길고양이 급식 관리 앱 "냥's 키친"(이하 "앱")을 제공하면서 이용자의 개인정보를 소중히 다룹니다. 이 방침은 앱이 어떤 정보를 어디에 저장하고, 누구에게 전달하는지 설명합니다.

1. 한눈에 보기

  • 앱은 회원가입이 없고, 이름·전화번호·이메일을 받지 않습니다.
  • 급식 포인트, 고양이 사진, 급식 시간 기록은 이용자의 휴대폰에만 저장되며 운영자 서버로 보내지 않습니다. 운영자는 이 정보를 볼 수 없습니다.
  • 지도 표시와 광고를 위해 아래 3번의 외부 서비스가 일부 정보를 처리합니다.

2. 휴대폰에만 저장되는 정보

정보용도저장 위치
급식 포인트 이름과 위치(위도·경도), 급식 주의 구역지도에 표시앱 전용 저장 공간
고양이 사진과 이름포인트별 고양이 기록앱 전용 저장 공간 (원본)
급식 시간, 알람 설정, 완료 기록급식 알림앱 전용 저장 공간

이 정보는 앱을 삭제하거나, 앱의 설정 → 모든 데이터 지우기를 누르면 즉시 삭제됩니다. 운영자에게 따로 요청할 필요가 없습니다.

3. 외부 서비스가 처리하는 정보

서비스처리되는 정보목적
카카오맵 (주식회사 카카오)지도를 그리기 위해 화면에 보이는 지역의 지도 요청, 기기 IP 주소 등 접속 정보지도 표시
OpenStreetMap / CARTO 지도 타일 (카카오맵을 쓸 수 없을 때)지도 요청, IP 주소 등 접속 정보지도 표시
Google AdMob (Google LLC)광고 ID 등 기기 식별자, IP 주소(대략적 위치 추정), 광고 노출·탭 등 상호작용, 앱 성능 진단 정보광고 표시, 광고 성과 측정, 부정 사용 방지

이용자의 정확한 GPS 위치는 지도에서 내 위치를 보여주는 데에만 휴대폰 안에서 사용되며, 운영자에게 전송되지 않습니다. 외부 서비스의 처리 방식은 각 회사의 방침을 따릅니다: 카카오 개인정보처리방침, Google 개인정보처리방침, Google 파트너 사이트·앱의 데이터 사용 방식.

4. 앱이 요청하는 권한

권한이유거부하면
위치 (앱 사용 중)지도를 내 위치로 이동지도를 직접 움직여서 사용할 수 있어요
알림급식 시간 알림알림이 오지 않아요

고양이 사진은 휴대폰의 기본 카메라 앱이나 사진 선택 화면을 통해 이용자가 고른 사진만 가져오며, 앱이 사진첩 전체에 접근하지 않습니다. 백그라운드 위치 권한은 사용하지 않습니다.

5. 광고 맞춤 설정 거부

휴대폰의 설정 → Google → 광고에서 광고 ID를 삭제하거나 재설정하면 맞춤 광고를 받지 않을 수 있습니다.

6. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

7. 보관 기간과 파기

운영자는 이용자의 개인정보를 직접 수집·보관하지 않습니다. 휴대폰에 저장된 정보는 2번에 적은 방법으로 이용자가 언제든 삭제할 수 있습니다.

8. 이용자의 권리

이용자는 휴대폰에 저장된 자신의 정보를 앱에서 직접 보고, 고치고, 지울 수 있습니다. 외부 서비스가 처리하는 정보에 대한 열람·삭제는 해당 회사에 요청할 수 있으며, 운영자에게 문의하시면 안내해 드립니다.
